# Shadow Escape

A scary first-person escape-room quiz game for Angels Bud students.
One student is the hidden killer. The others answer questions to open doors, finish tasks and escape.

- **Students** open `index.html` and enter the 4-letter room code.
- **Teacher** opens `teacher.html`, picks the map, subject and killer, then starts the game.
- Questions come from the teacher's published Google Sheet (CSV link pasted on the teacher page).

Modes: Classic (find and vote out the killer) and Survival (run from the killer, all doors locked).
